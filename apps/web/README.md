# swiftClaw Landing Page

Marketing site for [swiftclaw.online](https://swiftclaw.online) — Next.js App Router, Tailwind CSS v4, Framer Motion, GSAP.

## Develop

```bash
cd apps/web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Stack

- Next.js 15+ (App Router)
- Tailwind CSS v4
- shadcn/ui + 21st.dev registry components
- Framer Motion, GSAP ScrollTrigger

Deploy to Vercel with root directory `apps/web`.
